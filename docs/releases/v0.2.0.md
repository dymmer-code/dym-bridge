Dym Bridge 0.2.0 introduces the GoGPU desktop interface, with a compact dual-pane file browser and no CGo or embedded WebView.

- File checkboxes, double-click folder navigation, file-type icons, improved scrolling, compact toolbars and tooltips.
- Dymmer browser sign-in with SSH public-key provisioning. A master password is optional for new keys; existing encrypted keys remain protected.
- Sites lists the interfaces supplied by Dymmer and opens them through the SSH connection. Existing manual links remain available.
- Simplified saved-resource and INI connection setup, light/dark themes, native application menu and a transparent monochrome macOS tray icon.
- Restored local/remote file operations, drag-and-drop uploads, transfer progress and reconnection. Fixed the macOS window-close freeze.
- Branded macOS DMG installers with drag-to-Applications layout, plus Windows and Linux archives.

The standalone credential-encryption utility has been removed. Existing INI files and encrypted profiles remain compatible. macOS accessibility for individual GoGPU controls remains limited.

Choose `darwin_arm64.dmg` for Apple Silicon or `darwin_amd64.dmg` for Intel Macs. SHA-256 checksums are included in `checksums.txt`.
